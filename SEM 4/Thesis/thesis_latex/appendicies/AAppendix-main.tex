\chapter{GitHub Repository and Analytical Codebase}
\label{App:github}
The complete analytical codebase, Jupyter notebook, datasets, and generated figures for this study are publicly available at:

\begin{center}
\url{https://github.com/RemmyBisimbeko/Data-Science/tree/main/SEM%204/Thesis}
\end{center}

The repository contains:
\begin{itemize}
    \item \texttt{thesis\_airtel\_v5.ipynb} --- Complete Jupyter Notebook with all analysis
    \item \texttt{Datasets/} --- Anonymised dataset exports
    \item \texttt{Datasets/model\_results\_summary.csv} --- Model evaluation results
    \item All generated figures (ARPU distribution, voice usage, value segment distribution, Spearman correlation, model comparison, feature importance)
\end{itemize}
